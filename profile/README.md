# About Loobric

Read more at the homepage: https://loobric.com
or try out the sandbox at https://api.loobric.com/ui/


We are committed to make tool synchronization between platforms
as fluid and friction-less as possible.

We are also deeply committed to open-core principles

Here you'll find our open-source repositories, wikis, and bug trackers.  We are open to contributions!

The following repositories will be of most interest: 

- loobric-server:  Self hosted tool synchronization server.
- loobric-freecad:  The FreeCAD addon that talks to a smooth-core server
- loobric-linuxCNC:  A simple client that synchronizes a linuxcnc tooltable with a smooth-core server
- loobric-cli:  A CLI tool and python library for interacting with the server.  This is pip-installable and is the fastest way to start building a custom client.
