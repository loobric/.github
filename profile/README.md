# About Loobric

We are committed to make tool sychonization between platforms
as fluid and frictionless as possible.

We are also deeply committed to open-core principles

Here you'll find our open-source repositories, wikis, and bug trackers.  We are open to contributions!

The following repos will be of most interest: 

Smooth-Core:  Self hosted tool synchronization server.
Smooth-FreeCAD:  The FreeCAD addon that talks to a smooth-core server
Smooth-LinuxCNC:  A simple client that synchronizes a linuxcnc tooltable with a smooth-core server
loobric-smooth:  A CLI tool and python library for interacting with the server.  This is pip-installable and is the fastest way to start building a custom client.
